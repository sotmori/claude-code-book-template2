# 経費精算アプリ（Valance VCA）

Valance 上で動く経費精算アプリです。React + TypeScript（Valance VCA テンプレート）で作成しています。
開発ガイドは `AGENTS.md`（`CLAUDE.md` から参照）を参照してください。

## 機能

| 利用者 | できること |
|---|---|
| 申請者（アプリ権限「編集」） | 経費申請の作成・下書き保存・申請・取下げ・削除、明細ごとの領収書添付（PDF/JPEG/PNG 等、10MB まで）、差戻し理由の確認と再申請 |
| 承認者・経理（アプリ権限「管理」） | 承認待ち一覧、承認／差戻し（理由必須）、承認済み申請の精算済登録（支払日入力）、対象月・件名での検索、CSV 出力（明細単位） |

- 状態: 下書き → 承認待ち → 承認済（支払待ち） → 精算済（差戻し時は申請者が修正して再申請）
- 自分の申請は自分で承認できません（画面上で抑止）
- すべての操作は履歴（作成・申請・取下げ・承認・差戻し・精算）として申請に記録されます

## デプロイ

`deploy/expense-settlement-app.zip` をポータルのアプリ管理からアップロード（公開）してください。
ZIP のルートに `index.html`・`config.json`（アプリ名「経費精算」）・`database.json`（テーブル定義）・`thumbnail.png`（アイコン）が含まれます。

再作成する場合: `npm ci && npm run package`

## テスト用デモ版（ログイン不要）

`deploy/expense-settlement-demo.zip` はログインも Valance API も使わないテスト用ビルドです（アプリ名「経費精算（デモ）」）。

- 開くとすぐ使えます。画面上部のバーで「申請者／承認者・経理」を切り替えて、申請→承認→精算の流れを一通り試せます。
- データ（申請・領収書）はそのブラウザ内（localStorage / IndexedDB）にのみ保存され、他の人とは共有されません。「データを初期化」でサンプルデータに戻ります。
- `database.json` を含まないため、テーブルは作成されません。Valance にアップロードしても、静的ファイルとして任意の Web サーバーに置いても動きます。
- 本番用 ZIP にはデモ用のコードは含まれません。

再作成する場合: `npm run package:demo`

## 公開後の権限設定（ポータルで実施）

申請データ（`expense_reports` テーブル）と領収書ファイルは **本人のみ参照・更新できる** 設定（owner モード）です。
承認者が他の人の申請を扱えるよう、ポータルのアプリ設定で次を行ってください。

1. アプリのアクセス設定で、申請者のグループに「編集」、承認者・経理のグループに「管理」を付与する
2. アプリの「管理者グループ上書き」で、承認者・経理のグループに次を付与する
   - 全件参照（canReadAll）、全件更新（canUpdateAll）
   - ストレージ全件参照（canReadAllStorage）… 他の人の領収書を閲覧するため

## 制約・注意

- 領収書はファイルストアに保存されます。テナントのファイル数上限（既定 1,000 件）を共有するため、利用量が多い場合は上限の引き上げを依頼してください。
- 一覧は 1 回の表示で最大 2,000 件まで取得します。

## ローカル開発

```bash
cp .env.development.example .env.development   # VITE_API_TARGET / VITE_APP_ID を設定
npm ci
npm run dev                                      # http://localhost:3001
```

コード変更後は `npm run lint:fix` → `npm run tsc` → `npm run lint` を実行してください。

アイコンの元データは `design/icon.svg` です（`public/thumbnail.png` と `public/favicon.png` は同一ファイル）。
